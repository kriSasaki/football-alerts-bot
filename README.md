# 🏟 Sports Alerts Bot v2 — SofaScore Edition

Telegram-бот для мониторинга live-статистики **футбольных** и **баскетбольных** матчей с мгновенными уведомлениями. Работает через SofaScore API — **бесплатно, без API-ключа**.

## Возможности

- ⚽🏀 **Два вида спорта** — футбол и баскетбол
- 📅 **Матчи по дням** — листай ±7 дней с группировкой Live / Запланированные / Завершённые
- 🔔 **Гибкие алерты** — угловые, голы, владение, очки по четвертям, чёт/нечёт и др.
- 🎲 **Массовые алерты** — ставь алерт на ВСЕ матчи дня одной кнопкой
- 😴 **Умный polling** — будущие матчи не тратят запросы до начала
- 📊 **Live-статус** — смотри текущее значение статистики прямо в боте
- 🔐 **Авторизация** — управление доступом: whitelist или одобрение админом
- 🚀 **Источник данных** — SofaScore (бесплатно, без лимитов)

## Быстрый старт

### 1. Получи Telegram Bot Token

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`, следуй инструкциям
3. Скопируй токен

### 2. Установи Python 3.12+

Скачай с [python.org](https://www.python.org/downloads/).

### 3. Установи зависимости

```bash
cd football-alerts-bot
pip install -r requirements.txt
```

> **Windows**: если `curl_cffi` не ставится, попробуй `pip install curl_cffi --upgrade`. Эта библиотека нужна для обхода Cloudflare на SofaScore. Без неё бот попробует работать через `aiohttp`, но может получать 403 ошибки.

### 4. Настрой `.env`

Скопируй `.env.example` в `.env` (или отредактируй существующий `.env`):

```bash
cp .env.example .env
```

Обязательные поля:
```env
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
```

Опционально (авторизация):
```env
# Telegram ID админа (может одобрять/отклонять пользователей)
ADMIN_USERS=123456789
# Или список с моментальным доступом
AUTHORIZED_USERS=123456789,987654321
```

> Узнать свой Telegram ID: напиши [@userinfobot](https://t.me/userinfobot)

### 5. Запусти

```bash
python bot.py
```

## Авторизация пользователей

Бот поддерживает 3 режима:

| Режим | Настройка | Поведение |
|-------|-----------|-----------|
| **Открытый** | `ADMIN_USERS` и `AUTHORIZED_USERS` пустые | Все могут пользоваться |
| **Whitelist** | `AUTHORIZED_USERS=id1,id2` | Только указанные пользователи |
| **Одобрение админом** | `ADMIN_USERS=id1` | Новые пользователи отправляют заявку, админ одобряет кнопкой |

Одобренные пользователи сохраняются в файл `approved_users.json` — они не потеряются при перезапуске бота.

```
└── requirements.txt
```

## Как работает

1. Пользователь выбирает спорт → листает матчи по дням
2. Нажимает на матч → выбирает тип алерта (угловые, голы, Q1 чёт и т.д.)
3. Выбирает условие (> 8, >= 5 и т.д.)
4. Бот сохраняет алерт в SQLite
5. Polling-цикл (каждые 2 мин) проверяет live-статистику через SofaScore
6. Если условие выполнено → мгновенное уведомление в Telegram

**Оптимизации:**
- 1 запрос на ВСЕ live-матчи (не по одному)
- In-memory cache с TTL — повторные запросы не дублируются
- Будущие матчи (`kickoff_at > now`) не тратят запросы до начала

## Доступная статистика

### Футбол
| Ключ | Описание |
|------|----------|
| `corners` | Угловые удары |
| `goals` | Голы |
| `shots` | Удары (всего) |
| `shots_on` | Удары в створ |
| `fouls` | Фолы |
| `possession` | Владение мячом (%) |
| `yellow` | Жёлтые карточки |
| `red` | Красные карточки |
| `offsides` | Офсайды |

### Баскетбол
| Ключ | Описание |
|------|----------|
| `points` | Очки (тотал) |
| `q1_total` – `q4_total` | Очки по четвертям |
| `half1` | Очки 1-й тайм |
| `q1_even`, `q2_even` | Чётный тотал четверти |
| `q1q2_even` | Q1 и Q2 обе чётные |

## Настройки `.env`

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `TELEGRAM_BOT_TOKEN` | — | **Обязательно.** Токен от BotFather |
| `POLL_INTERVAL` | `120` | Интервал опроса live-матчей (секунды) |
| `SOFASCORE_MIN_INTERVAL` | `1.5` | Мин. пауза между запросами к SofaScore |
| `LIVE_CACHE_TTL` | `60` | Время жизни кэша live-матчей |
| `SCHEDULE_CACHE_TTL` | `300` | Время жизни кэша расписания |
| `MATCH_START_TOLERANCE` | `3600` | Предупреждение о задержке матча (сек) |
| `DATABASE_PATH` | `alerts.db` | Путь к SQLite базе |
| `ADMIN_USERS` | — | ID админов (через запятую) |
| `AUTHORIZED_USERS` | — | ID с моментальным доступом |

## Деплой

### Windows (текущий)
```bash
python bot.py
```
Для фонового запуска можно использовать Task Scheduler или `nssm` для запуска как службы Windows.

### Linux (systemd)
```ini
[Unit]
Description=Sports Alerts Bot
After=network.target

[Service]
User=your_user
WorkingDirectory=/path/to/football-alerts-bot
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
